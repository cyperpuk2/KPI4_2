UI-елементи: опис та приклади

01

Radiobutton

Радіокнопки дозволяють користувачу обрати один варіант із набору. Одночасно може бути обраний лише один.

  • Використовуються для взаємовиключних варіантів (наприклад, вибір статі).
  • Групуються разом візуально та функціонально.

02

Checkbox

Чекбокси дозволяють користувачу обрати один або кілька варіантів незалежно один від одного.

  • Використовуються для множинного вибору (наприклад, інтереси, налаштування).
  • Кожен чекбокс працює незалежно.

03

Text input

Поля введення тексту дозволяють користувачу вводити та редагувати текстові дані.

  • Використовуються у формах, рядках пошуку, коментарях тощо.
  • Можуть бути однорядковими або багаторядковими (textarea).

04

Tabs

Вкладки організовують вміст в окремі подання, доступні через клік по заголовках вкладок.

  • Використовуються для навігації між пов'язаними розділами (наприклад, профіль / налаштування).
  • Покращують зручність, зменшуючи перевантаження інтерфейсу.

05

Button

Кнопки запускають дії при натисканні (наприклад, відправити, зберегти, видалити).

  • Можуть мати різні стилі для акценту (основна, другорядна, небезпечна).
  • Використовуються для відправлення форм, навігації тощо.
Приклади
06

Text label

Текстові мітки надають інформацію або описують інші елементи інтерфейсу.

  • Використовуються для назв полів, інструкцій або повідомлень про стан.
  • Покращують доступність і зрозумілість інтерфейсу.

07

Link

Посилання переводять користувача на інші сторінки або ресурси.

  • Зазвичай підкреслені та виділені кольором для помітності.
  • Можуть відкриватися в тій самій або в новій вкладці.

08

Tooltip

Підказки показують додаткову інформацію при наведенні на елемент.

  • Використовуються для підказок, пояснень або додаткових деталей.
  • Покращують досвід користувача, не перевантажуючи інтерфейс.

09

Dropdown list

Випадні списки дозволяють користувачу обрати один варіант зі згортаного переліку.

  • Використовуються для вибору країни, налаштувань, фільтрів тощо.
  • Можуть підтримувати одиничний або множинний вибір.

10

Data grid

Таблиці даних відображають табличні дані з можливостями сортування, фільтрації та редагування.

  • Використовуються для електронних таблиць, адміністративних панелей, звітів.
  • Підтримують посторінкове виведення, пошук та редагування в комірці.
